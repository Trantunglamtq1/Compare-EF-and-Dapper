💻 So Sánh Cấu Trúc Code & Hình Dáng Cú Pháp

Dưới đây là so sánh song song hình dáng code của Entity Framework Core và Dapper trong từng kịch bản cụ thể.

🔷 Entity Framework Core (LINQ & DbContext)

// 1. Single Read according to Id Product? p1 = await db.Products.FindAsync(id); // 2. Filter & Sorting Query var list1 = await db.Products .Where(p => p.CategoryId == catId && p.Price >= 50m) .OrderByDescending(p => p.Price) .Take(50) .ToListAsync(); // 3. Multi-table Join (EF tự sinh JOIN) var list2 = await db.Products .Include(p => p.Category) .Take(50) .ToListAsync(); // 4. Bulk Insert await db.Products.AddRangeAsync(productBatch); await db.SaveChangesAsync(); // 5. Change Tracking Update var prod = await db.Products.FindAsync(id); prod.Price += 10m; await db.SaveChangesAsync(); // EF tự phát hiện Price đổi và sinh SQL UPDATE

🔶 Dapper (Raw SQL & IDbConnection)

// 1. Single Read according to Id var sql1 = "SELECT * FROM Products WHERE Id = @Id"; Product? p1 = await connection.QuerySingleOrDefaultAsync(sql1, new { Id = id }); // 2. Filter & Sorting Query var sql2 = "SELECT TOP (50) * FROM Products WHERE CategoryId = @CatId AND Price >= @MinPrice ORDER BY Price DESC"; var list1 = await connection.QueryAsync(sql2, new { CatId = catId, MinPrice = 50m }); // 3. Multi-table Join (Multi-mapping với splitOn) var sql3 = @"SELECT p.*, c.* FROM Products p INNER JOIN Categories c ON p.CategoryId = c.Id"; var list2 = await connection.QueryAsync(sql3, (product, category) => { product.Category = category; return product; }, splitOn: "Id"); // 4. Bulk Insert (Execute với IEnumerable) var sql4 = "INSERT INTO Products (Name, Price, ...) VALUES (@Name, @Price, ...)"; await connection.ExecuteAsync(sql4, productBatch); // 5. Explicit SQL Update var sql5 = "UPDATE Products SET Price = @Price WHERE Id = @Id"; await connection.ExecuteAsync(sql5, new { Price = newPrice, Id = id });

📊 Bảng So Sánh Tổng Quan EF Core vs Dapper

Tiêu chí Entity Framework Core Dapper
Phân loại Full-featured ORM Micro-ORM (Extension Methods)
Trải nghiệm lập trình (DX) Rất cao (Type-safe LINQ, Auto-complete, Migrations) Cao (Viết SQL thuần linh hoạt nhưng phải tự kiểm soát cú pháp chuỗi)
Cơ chế Map dữ liệu LINQ Expression Tree -> SQL AST -> Materialization Reflection.Emit (Tạo IL Code Deserializer động cực nhanh)
Change Tracking Có (Tự nhận biết đối tượng sửa/xóa/thêm để lưu) Không (Zero Change Tracking - Developer tự viết câu UPDATE)
Hiệu năng (Performance) Nhanh (Đã tối ưu Compiled Query Cache từ EF Core 6+) Cực nhanh (Tiệm cận ADO.NET thuần)
Phù hợp cho dự án Domain-driven design, CRUD nghiệp vụ phức tạp, Admin Panel High-throughput APIs, Reporting, Microservices, Batch processing
