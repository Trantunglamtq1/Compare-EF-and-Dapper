Dưới đây là so sánh song song hình dáng code của Entity Framework Core, SQL Command (Raw ADO.NET) và Dapper trong từng kịch bản cụ thể.

🔷 EF Core (LINQ & DbContext)

// 1. Single Read according to Id Product? p1 = await db.Products.FindAsync(id); // 2. Filter & Sorting Query var list1 = await db.Products .Where(p => p.CategoryId == catId && p.Price >= 50m) .OrderByDescending(p => p.Price) .Take(50) .ToListAsync(); // 3. Multi-table Join (EF tự sinh JOIN) var list2 = await db.Products .Include(p => p.Category) .Take(50) .ToListAsync(); // 4. Bulk Insert await db.Products.AddRangeAsync(productBatch); await db.SaveChangesAsync(); // 5. Change Tracking Update var prod = await db.Products.FindAsync(id); prod.Price += 10m; await db.SaveChangesAsync();

🟩 SQL Command (Raw ADO.NET)

// 1. 🔶 Dapper (Micro-ORM)

// 1. Single Read according to Id var sql1 = "SELECT * FROM Products WHERE Id = @Id"; Product? p1 = await connection.QuerySingleOrDefaultAsync(sql1, new { Id = id }); // 2. Filter & Sorting Query var sql2 = "SELECT TOP (50) * FROM Products WHERE CategoryId = @CatId AND Price >= @MinPrice ORDER BY Price DESC"; var list1 = await connection.QueryAsync(sql2, new { CatId = catId, MinPrice = 50m }); // 3. Multi-table Join (Multi-mapping splitOn) var sql3 = @"SELECT p.*, c.* FROM Products p INNER JOIN Categories c ON p.CategoryId = c.Id"; var list2 = await connection.QueryAsync(sql3, (product, category) => { product.Category = category; return product; }, splitOn: "Id"); // 4. Bulk Insert (Execute với IEnumerable) var sql4 = "INSERT INTO Products (Name, Price, ...) VALUES (@Name, @Price, ...)"; await connection.ExecuteAsync(sql4, productBatch); // 5. Explicit SQL Update var sql5 = "UPDATE Products SET Price = @Price WHERE Id = @Id"; await connection.ExecuteAsync(sql5, new { Price = newPrice, Id = id });

📊 Bảng So Sánh Tổng Quan EF Core vs SQL Command vs Dapper

Tiêu chí Entity Framework Core SQL Command (ADO.NET) Dapper
Phân loại Full-featured ORM Native ADO.NET Provider Micro-ORM (Extension Methods)
Trải nghiệm lập trình (DX) Rất cao (Type-safe LINQ, Auto-complete, Migrations) Thấp (Viết SQL thủ công, map tay từng cột) Cao (SQL linh hoạt, tự động map POCO)
Cơ chế Map dữ liệu LINQ Expression Tree -> SQL AST -> Materialization Manual DataReader Indexing / Casting Reflection.Emit (Tạo IL Code Deserializer động)
Change Tracking Có (Tự nhận biết đối tượng sửa/xóa/thêm) Không (Developer tự quản lý) Không (Zero Change Tracking)
Hiệu năng (Performance) Nhanh (Có Compiled Query Cache) Tối đa (Gốc của .NET Data Access) Cực nhanh (Tiệm cận ADO.NET thuần)
Phù hợp cho dự án Domain-driven design, CRUD phức tạp Hệ thống lõi siêu hiệu năng, High IOPS High-throughput APIs, Microservices, Reports
